# Calibrated super-resolution of public Visium hires images

Analysis code for the manuscript *Unlocking nuclear morphology in low-resolution public Visium images with calibrated super-resolution*.

About half of human 10x Visium series in GEO deposit only the Space Ranger `tissue_hires_image.png` (about 4 µm per pixel). This code trains a SwinIR ×8 model on TCGA-PAAD slides, measures the real hires degradation from public deposits that contain both the native scan and its hires image, calibrates the blur, and evaluates nuclear morphometry and morphology–expression associations on reconstructed images.

## Layout

```
scripts/        analysis and figure scripts (run from the repository root)
src/hemorph/    shared helpers (CellViT I/O, nucleus matching, H&E colour deconvolution)
env/            conda environments (hemorph: analysis; cellvit: CellViT++ inference)
```

Scripts are numbered in the order they were run. Each script states its inputs and outputs in its docstring; results are written to `results/` (not version-controlled).

## Data

All data are public:

- TCGA-PAAD diagnostic slides (NCI Genomic Data Commons);
- HEST-1k (Hugging Face `MahmoodLab/hest`);
- GEO series GSE211895, GSE327056, GSE274665, GSE282302, GSE299970 and GSE337859.

Input locations are set as constants near the top of each script (for example `/Volumes/INTENSO/...` for the TCGA slides, HEST-1k and GEO downloads) and must be adapted to the local copies.

## External dependencies

- **SwinIR.** Network definition `network_swinir.py` and the official `001_classicalSR_DF2K_s64w8_SwinIR-M_x{2,4,8}.pth` weights from https://github.com/JingyunLiang/SwinIR. The directory holding them is set in `sr08c_train_swinir.py`, `sr08t_x8_core.py` and `sr09_scale65_core.py`.
- **CellViT++.** https://github.com/TIO-IKIM/CellViT-plus-plus, SAM-H model, run in the `cellvit` environment through `scripts/run_cellvit_mps.py`.
- Trained models and per-figure source data: https://doi.org/10.5281/zenodo.24314114 (CC BY-NC-SA 4.0).

The blinded labelling and contour-tracing pages were served locally from small HTML templates that are not included. The resulting label and contour files are part of the source data.
